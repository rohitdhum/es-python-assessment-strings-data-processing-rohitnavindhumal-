# Question 1 :- Reverse a String

Function Name :- `reverse_string(text: str) -> str`

Problem :- Write a function that takes a string and returns it in reverse order.

Approach (Explaination) :- First, I created an empty string to store the reversed text. Then, I used a for loop to read the characters from the last position to the first position. I added each character to the new string and returned the final result.

Example:
        Input: hello
        Output: olleh

# Question 2 :- Count Vowels

Function Name :- count_vowels(text: str) -> int

Problem :- Write a function that counts the number of vowels in a given string.

Approach (Explaination) :- First, I initialized a counter variable to zero and stored the vowels are a, e, i, o, u in a string. Then, I converted the input to lowercase using lower() method and checked each character using a for loop. Whenever a character matched a vowel, I increased the counter by one. Finally, I returned the total count. Then it will show the output.

Example:
       Input: Hello World
       Output: 3

# Testing :-
I tested both functions with different inputs, including normal strings, lowercase letters, uppercase letters, strings without vowels, and empty strings. All test cases return the expected results.
